## 1. Classification Categories

Every item is classified as exactly one of:
- **A. VERIFIED PROFESSIONAL EXPERIENCE (`professional`)**: Work actually performed in an employment or internship role.
- **B. VERIFIED PERSONAL PROJECT (`project`)**: A project genuinely built or completed.
- *(Demonstrations built specifically for this website are classified as `experiment`, labeled as portfolio experiments or educational demonstrations.)*
- **C. FOUNDATIONAL KNOWLEDGE (`foundation`)**: Concepts or tools understood at an introductory or academic level.
- **D. CURRENTLY LEARNING (`learning`)**: Technologies actively being studied but not mastered.
- **E. FUTURE INTEREST (`exploring`)**: Technologies planned for exploration in the future.
